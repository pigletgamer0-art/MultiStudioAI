# Mod Studio para Sandboxels — v0.1

Editor de mods en JavaScript con tres pestañas: **Editor de código**, **Mis mods** y **Instalados**.

## Instalar

1. Entra a [Sandboxels](https://sandboxels.r74n.com).
2. Abre **Mods**.
3. Pega esta URL **completa** (termina en `.js`):

```
https://cdn.jsdelivr.net/gh/pigletgamer0-art/MultiStudioAI@sandboxels-mod-studio-v0.1/mod_studio.js
```

4. Pulsa Enter y recarga el juego.
5. Busca el botón **Mod Studio**.

URL alternativa, por si el CDN tarda en actualizar:

```
https://raw.githubusercontent.com/pigletgamer0-art/MultiStudioAI/sandboxels-mod-studio-v0.1/mod_studio.js
```

## Funciones

- Crear mods mediante código JavaScript.
- Guardar, activar, desactivar, duplicar, importar o exportar creaciones.
- Consultar y gestionar mods habilitados en Sandboxels.
- Guardado de proyectos solo en el navegador (`localStorage`).

**Estado**: prototipo v0.1. Sintaxis verificada; integración pendiente de comprobar en Sandboxels real. Antes de recargar, guarda tu mundo. Los mods JavaScript se ejecutan dentro del navegador, así que ejecuta solo código de confianza.

Publicado en una rama independiente para no afectar al proyecto MultiStudioAI de la rama principal.
